01 · 内置模块

工作台里的每一块积木

六个模块开箱即用，各自独立、也可互相配合。它们拼在一起，就是你的日常工作流。

MEMO

备忘快粘

把灵感随手写在彩色便签上，按标签整理、批量管理。

LAN

局域快传

在局域网内开启文件分享服务，其他设备通过浏览器即可访问并传输文件。

SSH

SSH 隧道

通过公网服务器建立 SSH 隧道，实现本地转发、远程映射（NAT）与 SOCKS5 代理。

SSH

SSH 客户端

管理 SSH 节点，打开交互控制台，并通过 SFTP 浏览与下载远程文件（含目录）。

K8S

K8s 管理

通过 kubeconfig 连接 Kubernetes 集群，查看工作负载与网络，对 Pod 进行日志、控制台与端口转发操作。

TOOLS

开发者工具

开发者高频小工具：随机密码、编码转换、JSON、时间戳、PDF 处理等。

02 · 特性

为效率而拼，为安全而固

本地优先、加密存储、静默升级 —— 工具的可靠性，就是工作流的可靠性。

/01

自动更新

检测到新版本自动下载，下载完成提示重启安装，始终用上最新能力。

/02

本地优先

备忘、节点、集群配置都保存在本机，数据自己掌控，离线照常工作。

/03

密钥加密

SSH 私钥与密码使用系统级加密存储，不落明文。

/04

深色护眼

跟随系统的日间 / 夜间主题，长时间使用也从容。
